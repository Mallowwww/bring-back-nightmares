# Bring Back Nightmares !
This mod is an attempt to bring back the older bed mechanics removed in release version 1.0 with some modern improvements.
## What does this mod do?
Rather than deciding if you can sleep depending on proximity to living mobs, you'll be awoken mid-sleep if mobs can path to your bed. This prevents players from just placing a bed in the middle of the woods, and encourages them to make a proper, well-lit house.
